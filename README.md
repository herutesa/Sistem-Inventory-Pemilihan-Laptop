# Sistem Inventory dan Pemilihan Laptop

Aplikasi berbasis web untuk:
- Manajemen inventory laptop
- Rekomendasi pemilihan laptop berdasarkan kebutuhan aplikasi
- Menggunakan metode SPK (SAW / MOORA)

## Fitur
- Input data laptop
- Kriteria dan bobot penilaian
- Perhitungan rekomendasi
- Laporan hasil seleksi

## Teknologi
- PHP
- MySQL
- Laragon
- Git & GitHub
